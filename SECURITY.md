# Security

This app is a local notebook, not an authenticated server or encrypted vault. Anyone with access to its browser profile or backup files may read its farm records. A local farm name is not an identity or access-control boundary.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/twe-cloud/thara-farm-local/security/advisories/new). Private reporting is enabled for this repository. Do not include real farm records, credentials or unnecessary personal information; use a synthetic reproduction. Do not publish exploit details or secrets in an issue.

No backend is needed. Do not deploy the legacy sync worker, cloud analytics, release scripts or provider configuration with this local edition. Any future server or collaboration feature needs a separate threat model and explicit consent.
